### WhatsApp Multi-Bot


## Setup
1. Clone this repo: `git clone <your-repo-url>`
2. Install dependencies: `npm install`
3. Edit `index.js` and add your phone number.
4. Run: `npm start`
5. Copy the **Pairing Code** from the terminal and enter it on your phone (Linked Devices > Link with Number).

## Features
- Pair Code Login
- Auto-read & Typing
- Anti-link (Group)
- Games & Downloaders
